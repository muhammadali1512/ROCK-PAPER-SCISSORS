# 🎮 Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built as a **frontend project** using **HTML, CSS, and JavaScript**.  
This project focuses on clean UI, DOM manipulation, and **modular programming** in JavaScript.

---

## ✨ Features

- 🎯 Interactive gameplay (Rock, Paper, Scissors)
- 🤖 Random computer choice generation
- 📊 Real-time score tracking
- 🎨 Clean and responsive UI
- 🧩 Modular JavaScript code structure

---

## 🛠️ Technologies Used

- **HTML** – Structure of the game
- **CSS (Flexbox)** – Styling and layout
- **JavaScript (ES6)** – Game logic and DOM manipulation

---

## 🧠 Programming Approach

This project is built using **modular programming** in JavaScript:

- Separate functions for each responsibility
  - `genCompChoice()` → generate computer move
  - `drawGame()` → handle draw condition
  - `showWinner()` → update score & UI
  - `playGame()` → main game logic
- Clean separation of concerns
- Readable and maintainable code

This approach makes the code easier to understand, debug, and extend.
